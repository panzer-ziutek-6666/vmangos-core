# Telemetry — isolated A71 candidate

Collector runs outside IIS as Administrator and performs only the two fixed SOAP reads and schema/aggregate SQL SELECTs already verified against tomaszkubiak-courses/vmangos-core@14d19f56fc436097ac16d8355315d151ab4f5b41. IIS reads schema-1 JSON; it receives no database or game credentials. Three control actions and their authorization/CSRF stay intact. Account administration remains disabled.

`GET /api/telemetry` reads at most 32768 bytes, rejects duplicates, missing fields, unsupported schemas, unknown properties, invalid/reconciled counters, and a different mangosd PID/creation generation. It reuses the A70 bounded asynchronous WMI cache. Each source sample expires after 30 seconds; errors and stale samples have null data. One source failure does not erase a successful independent source. Peak is world sessions since world start, not a historical human-player record. AI means characters.online=1 joined to the current configuration's account prefix, not a verified in-memory bot count; other accounts can contain bots. Inventory and online observations are not atomic.

`tools/Collect-Telemetry.ps1` is a one-shot collector for this isolated build stage. Output is written atomically under its unique build directory, outside wwwroot and diagnostics. SQL credential options use a new protected temporary directory and are deleted in finally. Existing GM-6 game credentials are supplied locally. No permanent credential storage, recurring collector task, IIS file ACL, repository mutation or deployment is performed in A71. Production collection scheduling and file access must be verified in a later stage.
